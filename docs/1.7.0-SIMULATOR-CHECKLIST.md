2026-09-15：使用者已授權合入原 `RainyClock-iOS/`。開啟本目錄的 `RainyClock.xcodeproj`、RainyClock scheme，使用 iPhone 模擬器執行。App 應為原本的 `com.shukaihu.RainyClock`、版本 **1.7.0 (29)**；先前獨立預覽及合入前備份仍保留，沒有提交 App Store。

- [ ] 最左頁是「鬧鐘」，另一頁是「設定」；鬧鐘頁呈現狀態。標準文字大小下，主要鬧鐘資訊完整可見，不需為了設定完成訊息上下滑動。
- [ ] 鬧鐘上的時間、路線、日曆等資訊可跳到對應設定位置；返回後仍可看見狀態，不將狀態塞進時間編輯頁。
- [ ] 設定分類依序為「時間／路線／日曆／其他」，保留原深色、藍色與圓角風格。
- [ ] 時間頁改星期、時間或雨天選項後直接保存；離開再返回值仍一致。沒有「套用變更」按鈕、設定完成橫幅或「變更會自動更新」註解。

- [ ] 「其他」提供支援與「通知與背景更新」，沒有「排程與資料」分類。

## 日曆與地圖

- [ ] 「日曆」可進入原月份編輯器、選擇官方假日來源、修改單日照響／略過；關閉日曆後保留設定，重新打開仍可查看。
- [ ] 同一分類可進入天災設定與停班停課地圖。天災預設關閉；上班、上課可分別選取，兩者同時開啟時採兩者皆停止才略過。
- [ ] 住家／目的地行政區保存正確；從地圖定位地點不會自行覆寫設定或增加通勤途中地區。
- [ ] 地圖切換今天／明天、放大縣市、選鄉鎮／列表後可看公告原文；返回全台可見澎湖、金門、馬祖及烏坵小圖。
- [ ] 開啟地圖「示範」時明確標示示範資料，可辨識正常、停班停課、僅停課、僅停班、部分公告及未確認六種狀態。退出示範不保留虛構公告或改動鬧鐘。
- [ ] 地圖來源與授權資訊可查看；原始圖資是 2025-03-18 版，圖形僅用來瀏覽公告。

若只要直接查看獨立地圖範例，Debug 可使用啟動參數 `-disaster-map-preview`；加上 `-disaster-map-county 新北市` 可直接看縣市。此入口使用獨立設定、略過通知註冊，不等於已驗證正常 App 的完整導覽；Release 沒有此入口。
