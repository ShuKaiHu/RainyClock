# Rainy Clock — 1.7.0 UI/UX 獨立提案

日期：2026-09-14。狀態：**第二版互動預覽，尚未接入原生 App**。

使用者要求保留原本風格，只調整 UI/UX，且不得覆蓋 1.7.0。這個資料夾只包含獨立預覽；沒有修改 Swift、Xcode 專案、版本號或既有原生工作內容。

## 本次使用者修正

1. 移除「套用變更」與「更新鬧鐘」的常駐按鈕。選項調整後自動更新，不需要再按確認或關閉面板才生效。
2. 路線頁恢復 1.7.0 的配置：獨立住家／工作輸入欄、方式膠囊、240 pt 地圖、預估時間及距離卡片、原本藍色漸層路線天氣卡片。
3. 設定的時間顯示摘要與選項名稱改為「12小時制」。實際鐘面依然顯示上午／下午。

## 預覽內容

- `rainy-clock-ux.html`：可在 Codex 對話中互動的原始稿。
- `preview.html`：同一份稿的瀏覽器預覽包裝。
- `alarm.png`、`settings.png`、`route.png`、`route-weather.png`、`automatic-update.png`、`schedule-detail.png`、`compact-alarm.png`：第二版版面檢查截圖。
- `route-map.png`、`route-map.json`：透過 Apple MapKit 產生的公開示範路線底圖與幾何資料，日期 2026-09-14；底圖亦嵌入互動稿，預覽不需再連線查詢地圖。

保留原生 ContentView 的黑底、深灰卡片（約 #1f1f21）、藍色操作、24–30 pt 圓角與底部膠囊導覽。

## 操作邏輯

- 導覽維持 **鬧鐘 → 路線 → 設定**，開啟即進入最左邊的鬧鐘。
- 鬧鐘首頁保留一般起床時間、目前已排程的下次響鈴、重複日期，以及下雨提早／鈴聲／稍後提醒入口。細項進面板編輯，首頁不需上下捲動。
- 影響鬧鐘的選項與日期更動會自動更新。快速連續編輯只發布最後一次選擇；更新完成前仍顯示上次成功排程。模擬等待約 650 ms，用來展示更新中狀態。
- 編輯面板維持開啟，在面板內顯示「正在自動更新／已自動更新」。成功時不強制跳頁，也不自動打開另一張詳情面板。面板已關閉時可顯示頂部短提示。
- 右上角持續顯示實際排程狀態。更新失敗不清除原排程，以持續顯示的錯誤與「重試」提供復原入口；重試不是日常設定的必要步驟。
- 沒有響鈴日期時自動改成無排程；若仍有日期但住家／工作地址尚未補齊，保留舊排程並提示完成路線，不聲稱設定成功。
- 時間與下雨設定面板只留右上角關閉入口，沒有外觀像確認操作的大型返回按鈕。
- 設定仍以「響鈴日期」「提醒與顯示」「支援」分組；停班停課偏好放在日期設定的次要入口，標明不會自動停止鬧鐘，兩個偏好保持獨立。
- 保留 50 pt 廣告版位、20 pt 回報區與底部安全區，不載入廣告 SDK。

## 驗證

以瀏覽器實際操作並檢查：

- 一般 393 × 780 與小螢幕 320 × 667，包含廣告與回報區；鬧鐘首頁沒有垂直或水平溢出。
- 在面板保持開啟的情況下，修改提早時間與起床時間後自動成功，無須按鍵確認。
- 連續修改提早分鐘數，最後發布最後一次選擇；成功前保留原排程。
- 行事曆開啟與假日手動覆寫會自動更新，沒有殘留的套用按鈕。
- 設定摘要與格式選項皆顯示「12小時制」，仍能切換 24 小時制並正確顯示鐘面。
- 模擬更新失敗保留原排程，點「重試」後成功；面板保留焦點，Escape 可以關閉。
- 路線頁恢復兩個地址欄、四個方式膠囊、地圖、兩張指標卡片與分段天氣卡片。
- JavaScript 執行沒有未處理錯誤。

## 預覽範圍

這是 UI/UX 原型，**不會設定真實鬧鐘**。時刻、天氣、權限與涵蓋日期是示範；日曆只示範 2026 年 9 月假日。所有更改只存在本次預覽記憶體，重新開啟即重設。

路線版面依原生程式恢復，地圖使用 MapKit 的台北車站至台北 101 開車路線快照；可拖曳並置中，但不是完整原生 MapKit 互動。其他地址不會觸發實際搜尋，其他交通方式只示範兩端位置。天氣不是真實預報。音訊、AI 語音、系統權限、廣告同意、郵件及外部連結仍以說明面板呈現。

本次沒有建置原生 App。採用後仍需在獨立原生版本確認 Dynamic Type、VoiceOver、各機型安全區、實際廣告高度及自動重新排程的成功／失敗行為。
