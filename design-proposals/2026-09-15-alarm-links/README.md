# Rainy Clock UI/UX 提案 · 鬧鐘首頁與設定入口

延續 `../2026-09-15-settings-hierarchy/` 的獨立提案，未改動 1.7.0 原生程式。

- 主頁「狀態」改為「鬧鐘」，並以鬧鐘首頁開啟預覽。
- 設定分類改為「時間／路線／日曆／其他」。
- 鬧鐘首頁的資訊可直接前往對應設定；設定仍即時生效，沒有套用按鈕或完成橫幅。

## 資訊入口

| 首頁資訊 | 目的地 |
| --- | --- |
| 下次響鈴／啟用資訊 | 設定 → 時間 |
| 響鈴日期、日曆摘要 | 設定 → 日曆 |
| 大時間 | 設定 → 時間 → 起床時間 |
| 因雨提早 | 設定 → 時間 → 下雨提早 |
| 一般起床時間提示 | 設定 → 時間 → 起床時間 |
| 時間摘要 | 設定 → 時間 |
| 路線摘要 | 設定 → 路線 |
| 前晚提醒 | 設定 → 時間 → 前晚提醒 |
| 通知／背景資訊 | 設定 → 其他 → 通知與背景更新 |
| 天氣待更新、天氣更新時間 | 設定 → 路線，定位到路線天氣 |

前晚提醒與通知／背景資訊分為並排的兩個入口，避免同一塊資訊導向錯誤位置。互動使用原生按鈕，可透過鍵盤開啟；關閉設定面板後，焦點回到對應設定項目。

## 檢查

已驗證十個資訊入口、分類名稱、設定面板、返回路徑、鍵盤操作、焦點回復與自動更新，沒有 JavaScript 執行錯誤。已檢視一般與小螢幕截圖。393 × 780 及 320 × 667 的鬧鐘首頁與時間設定均可完整顯示，沒有水平溢出。

此提案只使用預覽內的暫存設定、既有 Apple MapKit 快照與示範天氣。沒有連接原生鬧鐘、變更 iPhone 系統權限或送出訊息。
