# Rainy Clock — 第三版 UI/UX 預覽

2026-09-15。此版接續使用者對第二版的回饋，**僅為獨立互動預覽，沒有修改原生 1.7.0**。前一版保留在 `../2026-09-14/`。

## 本次調整

- 底部導覽：**鬧鐘 → 狀態 → 路線 → 設定**。鬧鐘維持最左邊與預設頁面。
- 鬧鐘改成和設定頁相同的分組清單：「時間與日期」「雨天調整」「聲音與提醒」。只有選項與目前值，移除大時鐘、右上角狀態、下次響鈴與頁底說明。
- 新增獨立「狀態」頁：顯示上次成功設定的下次響鈴、日期、雨天提前原因，以及已生效的起床時間、重複日期、鈴聲與天氣資訊。
- 刪除行事曆設定中的「排程與資料」整組及其入口。沒有把原本的假日資料管理區搬到狀態頁。
- 移除一般編輯頁和面板的說明段落、成功提示、儲存字樣。保留少量必要的錯誤、未支援功能與破壞性重設說明。
- 選項仍自動更新，不需按確認。狀態頁更新前後使用不同快照，失敗保留原排程，提供重試。其他頁只在「狀態」導覽出現需要處理的提示點。
- 沿用第二版的原生路線配置、12小時制名稱、黑底深灰卡片、藍色操作與膠囊導覽。

## 驗證

已用瀏覽器操作並檢查：

- 鬧鐘頁只有六個選項，沒有右上角狀態、下次響鈴或自動更新註解。
- 正常 393 × 780、小螢幕 320 × 667 的鬧鐘頁皆無上下或左右溢出，包含底部導覽、廣告與回報區。
- 修改時間與雨天設定後自動更新狀態，連續編輯採用最後一次選擇；不顯示成功 toast 或面板儲存註解。
- 更新失敗時保留原響鈴時間及原生效設定，重試成功後更新，導覽提示點隨之消失。
- 沒有重複日期時顯示無排程；下一個日期沒有天氣時使用一般時間，明確顯示待更新。
- 行事曆沒有「排程與資料」及其入口；12／24 小時切換同步套用到狀態頁。
- 路線仍保留原版兩個地址欄、四個方式膠囊與地圖。
- 無 JavaScript 未處理錯誤。

## 邊界

這是示範資料與本地互動，沒有註冊系統鬧鐘、呼叫語音生成、載入廣告或更動通知權限。示範日期固定為 2026-09-15 晚上；地圖沿用第二版嵌入的 Apple MapKit 快照。日曆只示範 2026 年 9 月假日。重開預覽即還原初始設定。

尚未建置或驗證原生 App。未來接入時，重要失敗、權限與日期排程到期等需要處理的狀態也應集中在狀態頁，避免為了精簡說明而隱藏實際問題。
