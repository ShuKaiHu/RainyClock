# Rainy Clock 1.7.0 UI/UX 提案 · 狀態與設定分層

此資料夾為獨立互動提案，保留前一版於 `../2026-09-15/`，未更改 1.7.0 原生程式。

## 導覽

- 主要頁面為「狀態」與「設定」。
- 設定內依序為「鬧鐘／路線／日曆／其他」，直接切換；初次預覽顯示鬧鐘設定。
- 鬧鐘保留時間、重複日期、提早時間、降雨門檻、鈴聲、稍後提醒，加上前晚提醒。時間顯示格式放在起床時間面板，使用「12小時制」文字。
- 路線沿用上一版恢復的地址、交通方式、地圖、時間與距離、路線天氣布局。
- 日曆獨立管理日期規則、休假日來源、指定日期、停班停課偏好。每週重複仍由鬧鐘分類管理。
- 其他只包含「通知與背景更新」及「支援」；支援包含隱私與廣告、使用說明與關於。

## 狀態與互動

狀態由目前生效的設定推算，包含下次響鈴、下雨提早原因、路線、日期規則，以及前晚提醒和通知／背景更新狀態。四個分類並非必須逐頁開啟的完成清單；預設值與關閉選項也能形成有效設定，支援頁不影響響鈴時間。

選項修改後自動更新。沒有套用按鈕、頂部完成提示或設定頁底部自動儲存註解。更新失敗時，狀態頁顯示問題並保留上次生效設定；更新成功不彈出提示。螢幕閱讀器仍可收到儲存結果。

## 驗證

已以 Chromium 檢查雙層導覽、七個鬧鐘選項、12／24 小時顯示、即時儲存、前晚提醒、日曆指定日期、權限示範、缺少路線、更新失敗與原設定保留、無響鈴日期，以及分類返回路徑。沒有 JavaScript 執行錯誤。

一般手機寬 393、高 780，以及小螢幕寬 320、高 667 均可完整顯示鬧鐘設定。鬧鐘內容高度分別為 568 與 455，未產生上下或左右溢出。已檢視本資料夾中的畫面截圖。

原生 `RainyClock`、`RainyClockTests`、`RainyClock.xcodeproj`、`docs` 的修改前後差異檔完全相同。

## 預覽範圍

`rainy-clock-ux.html` 為對話內互動來源；`preview.html` 為本機檢查用頁面。操作與儲存皆為此次預覽內的示範狀態，重新載入後回到初始值。地圖沿用既有 Apple MapKit 快照，時間與天氣使用 2026 年 9 月的示範資料，未連接即時查詢或原生鬧鐘服務。系統權限面板不會變更實際 iPhone 權限。停班停課仍僅為偏好，不模擬尚未提供的自動取消功能。
